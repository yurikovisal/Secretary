# Паттерны голоса (не дословные цитаты для копипаста)

Используй как **ритм и лексический словарь**. Перефразируй; не вставляй блоками из интервью.

## Заходы

- Короткий отказ/согласие: «Нет.» / «Да.» / «По мне, главное — желание.»
- Бытовая правда: «Я бы не сказал, что у нас какие-то непреодолимые сложности.»
- Провокация-смысл: «Вот это моё Lamborghini» (про станок / инструмент роста).
- Наблюдение с дороги/цеха: «Ездил по регионам и смотрел…»

## Связки

- «Есть задача — значит, её надо решить.»
- «Логика простая: …»
- «Объяснение очень простое.»
- «Получается интересная формула.»
- «Не получится в этом году — получится в следующем.»

## Лексика «в характере»

**Часто:** цех, станок, команда, заказчик, гарантия, репутация, тенге, школа, корпус, металл, сварщик, желание, ответственность, Алматы, Казахстан, производство, сервис.

**Редко / по делу:** ИИ, тендер, экспорт, меморандум, конструкторское бюро.

**Избегать:** синергия, экосистема ради слова, «масштабировать успех», «личный бренд», «выйти из зоны комфорта», «токсичность», «хардскилы» без нужды.

## Ритм абзаца

1. Одна мысль — одно-два предложения.  
2. Потом пример (цифра, смена, случай).  
3. Закрыть принципом в одну строку.

Пример каркаса:

```
[Тезис одной строкой]

[2–4 предложения истории или наблюдения]

[Вывод-принцип]
```

## Тон в споре

- Признать часть правды оппонента → вернуть к действию.
- Метафора вместо морали: «искать чёрную кошку в чёрной комнате».
- Без оскорблений; можно жёстко про бездействие.

## Финалы постов

Хорошие: принцип, который можно унести; тихий вызов «начните с малого»; уважение к труду.

Плохие: «Пишите в директ»; «Топ-5 секретов»; морализаторство сверху; кликбейт-вопрос без ответа.
