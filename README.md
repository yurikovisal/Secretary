# ATON+ — Андрей Краснокуцкий

Одностраничный сайт-визитка, реализованный по макету «пиксель-в-пиксель».
Статика без сборки: откройте `index.html` или отдайте папку любым статическим сервером.

```
python3 -m http.server 8000     # шрифты требуют http(s), не file://
```

## Структура

```
index.html              разметка страницы
assets/css/styles.css   стили (макетная сетка 1440px, панель 1336px)
assets/css/fonts.css    @font-face для Manrope (локальные подмножества)
assets/fonts/           Manrope woff2: latin, latin-ext, cyrillic, cyrillic-ext
assets/js/main.js       галерея, карусель кейсов, счётчики, меню, scroll-spy
assets/img/             портреты (PNG с прозрачностью) и сцены (SVG)
```

## Макетные величины

Холст макета — 1440px; полотно страницы 1336px (отступ 52px по краям),
секции идут вплотную и разделены линией `rgba(255,255,255,.062)`.
Высоты секций совпадают с макетом с точностью до 1px:

| секция | макет | реализация |
|---|---|---|
| hero | 713 | 713 |
| биография | 420 | 420 |
| производство | 433 | 434 |
| Smart панели | 407 | 406 |
| кейсы | 288 | 291 |
| Алматы | 330 | 332 |
| подвал + CTA | 360 | 360 |

Типографика: Manrope — H1 62/62 (-0.02em), H2 31.5/36 (-0.015em),
основной текст 14/22, надзаголовки 11px с трекингом 0.13em.

## Изображения

Портреты (`hero-portrait.png`, `bio-portrait.png`) получены из исходных
студийных фотографий: фон снят по градиентной модели подложки, студийные
блоки удалены отдельной маской.

Остальные кадры макета (детские площадки, Smart-панель в аудитории,
парк, панорама Алматы, ночной город) исходниками не сопровождались —
на их месте векторные сцены в `assets/img/*.svg`, повторяющие композицию,
кадрирование и цветовой строй макета. Их достаточно заменить на фотографии
с теми же пропорциями: разметку и стили менять не нужно.

## Адаптив

Брейкпоинты 1400 / 1180 / 1000 / 700px. На ≤1000px навигация сворачивается
в бургер-меню, колонки складываются в одну, кейсы остаются горизонтальной
прокруткой. Горизонтального переполнения нет ни на одной ширине.
